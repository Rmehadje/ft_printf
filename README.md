# ft_printf

**ft_printf** is a 42 project designed to deepen your understanding of variadic functions, formatting output, and managing different data types in C. The goal is to create a simplified version of the standard C library's `printf` function, supporting a variety of conversion specifiers and flags.

## Features

- 🔠 **Formatted Output**: Supports formatting specifiers for integers, characters, strings, pointers, and more.
- ⚙️ **Custom Conversion Specifiers**: Implements a subset of the standard `printf` functionality, including `%c`, `%s`, `%p`, `%d`, `%i`, `%u`, `%x`, and `%X`.
- 💥 **Handles Flags**: Supports basic formatting flags like `-` (left alignment), `0` (zero padding), and precision.
- 🧩 **Modular Design**: The code is structured to be easily extendable and maintainable.

## Function Prototype

```
int ft_printf(const char *format, ...);
```
